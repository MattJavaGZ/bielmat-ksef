# BielmatKSeF

## 📋 O projekcie

Aplikacja stworzona dla pewnej firmy w celu przyśpieszenia wprowadzania faktur do Ksef przed wdrożeniem programu docelowego.

1. Wczytywanie pliku PDF z fakturą.
2. Wyciąganie danych z pliku PDF.
3. Parsowanie danych z pdf na obiekt faktury za pomocą wyrażeń regularnych.
4. Sprawdzenie poprawności danych faktury, wyświetlenie ewentualnych warningów oraz możliwość edycji danych.
5. Generowanie pliku XML zgodnego z wymaganiami KSeF.
